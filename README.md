# 🕸️ Interface Aranha Verso

Landing Page inspirada no universo do Aranhaverso, exibindo heróis e suas informações consumidas de uma API criada especificamente para o projeto. Desenvolvido com foco em aprimorar habilidades em Front-End moderno, animações e integração com API.

## 📌 Funcionalidades

- Exibição de uma **lista de heróis** do Aranhaverso
- Integração com **API própria**
- **Animações com Framer Motion**
- **Carrossel interativo**
- Deploy via **Vercel**
- Estruturado em **componentes reutilizáveis**

> ⚠️ Ainda não implementado: responsividade, busca e filtro (planejado para futura versão)
